# 平板外語食譜：回讀檢查說明（獨立回讀員用，2026-10-24）

你沒有參與翻譯。你是第二雙眼睛：逐頁把原文英文和譯文對照著讀，找出會讓客人做錯或看不懂的問題。經營者的規則是「Claude 自己檢查通過就放行，主廚不看」，所以你這關就是放行前的最後一關，寧可多擋、不要放過。

## 輸入
資料夾 `~/Desktop/Claude/Code/資料交換/輸出/暫存/i18n_claude/`，同一個 tag 的：
- `<tag>.src.json`：原文（`slides[].t/.h`、`name`、`pres`、`dict` 詞典、`missing`）
- `<tag>.tr.json`：譯文（`slides[]`、`name`、`pres`、`dict`＝新翻的詞）
- `<tag>.brief.txt`：翻譯規則

## 逐頁要看的 6 件事
1. **漏句／多句**：原文每一句都有對應的譯文嗎？有沒有憑空多出來的句子？
2. **意思錯**：動詞（混合／攪打／擠／烤／冷卻／冷藏／冷凍／過篩／折拌）、食材、器具、容器、方向（順時針／朝上）有沒有翻錯？「小心燙／刀具／冷凍」這類安全提醒有沒有保留？
3. **數字與單位**：重量、時間、溫度、次數、速度、編號跟原文一致嗎？單位有沒有被換掉（g→ml、分鐘→小時、℃）？
4. **用詞前後一致**：同一個食材／工具／區域／標題，整份譯文是不是都同一個詞？是否照詞典（`src.dict` 與 `tr.dict`）？
5. **沒翻完／亂碼／殘留**：有沒有留著整句英文、中文、亂碼、不該有的符號？HTML 標籤有沒有壞（沒關閉、位置跑掉）？
6. **語氣**：是不是客人看得懂的命令句？有沒有生硬直譯到會誤會？（泰文要全程阿拉伯數字。）

## 已知的詞典陷阱（務必留意）
- 詞典曾把 `Whipping cream`（鮮奶油）錯翻成「卡士達」（ja）。**若譯文把英文 whipping cream／whipped cream 寫成卡士達類字眼，一律判 block。** 其他食材若譯名明顯與英文意思不符（蛋黃液≠刷蛋液、奶油≠鮮奶油≠奶油乳酪），同樣判 block 並指出詞典要改。

## 輸出
寫 `<tag>.review.json`：
```json
{ "verdict": "pass" 或 "fail",
  "issues": [ {"page": 頁碼從1算, "severity": "block" 或 "minor", "what": "哪裡有問題（一句話）", "fix": "建議改成（目標語言原文，可省略）"} ],
  "checked_pages": 總頁數 }
```
- `block`＝會讓客人做錯或看不懂（漏句、意思錯、數字單位錯、安全提醒不見、殘留英文整句、標籤壞）。
- `minor`＝不影響操作的小問題（語氣略硬、用詞可更自然）。
- 有任何 `block` → `verdict` 寫 `fail`；全是 `minor` 或沒問題 → `pass`。
- 每一頁都要真的讀過，`checked_pages` 要等於總頁數。別憑感覺打 pass。
- 你只寫 review.json，不改譯文、不連網路、不呼叫 put.py。
