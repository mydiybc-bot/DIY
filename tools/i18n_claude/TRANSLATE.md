# 平板外語食譜：翻譯作業說明（Claude Code 版，2026-10-24）

一份工作＝一支食譜 × 一個語言。工作資料夾：`~/Desktop/Claude/Code/資料交換/輸出/暫存/i18n_claude/`，檔名 `<前8碼>_<語言>`。

## 你拿到什麼
- `<tag>.src.json`：`name`（英文名｜中文名）、`pres`（保存方式）、`local`（這個語言的甜點在地名，有就用）、`slides`（`k` 頁碼從 0、`t` 標題、`h` 內文 HTML）、`dict`（詞典已有的譯名，必須照用）、`missing`（詞典缺的詞，你要翻；`zh` 是台灣中文原名，英文有歧義時以中文意思為準；越南文若有 `backend` 直接用它）。
- `<tag>.brief.txt`：完整翻譯規則（含詞典）。**先讀它，照做。**

## 你要產出
寫一個 `<tag>.tr.json`：
```json
{ "name": "...", "pres": "...",
  "slides": [ {"k":0,"t":"...","h":"..."}, ... ],
  "dict": [ {"kind":"item","en":"原英文詞","tr":"譯名"}, ... ] }
```
- `slides` 頁數、`k` 與原稿完全一致（一頁都不能少、不能合併）。
- `dict` 只放 `missing` 裡的詞（kind、en 照抄，加上 tr）。`dict` 已有的詞不要重翻，內文遇到就照詞典。
- `name`：有 `local` 就用 `local｜`＋原中文名部分（伺服器也會強制這樣改）；沒有就把英文部分翻成目標語言，後面保留「｜中文名」。
- `pres`：保存方式照翻，保留換行（\n）。原稿是空的就留空。

## 硬規則（伺服器會再驗一次，不過就不放行）
1. 每個數字（重量、時間、溫度、速度、次數、編號）一個都不能少、不能改，一律用阿拉伯數字（泰文也是，不用泰文數字）。
2. `[[IMG1]]` 這種圖片佔位符原封不動留在原位置、數量不變。
3. HTML 只能有 `<p>`、`<p class="c">`、`<br>`、`<b>`、`<u>`、`<i>`、`<font color="...">`；標籤包住對應的譯文，跟原稿同位置。
4. 不增句、不刪句、不合併、不重排；編號（1. 2. 3.）和換行保留。
5. emoji 與符號（●、※、⭐、►、【】、［］）保留。「DIY Tip」翻成保留 DIY 這個字的短標籤。
6. 同一個英文標題每次出現都要同一個譯法；帶數字的相似標題（Frosting 1／Frosting 2）用同一組字。
7. 食材、工具、取放區出現時，用詞典的譯名（`dict` 已有的＋你為 `missing` 新翻的），整份食譜一致。
8. 語氣照 brief 的 target style。不要留下未翻的英文整句（品牌名如 Oreo 可保留）。
