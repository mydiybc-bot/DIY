食譜成本分析（資料來源與維護）
  1. 配方＝BOM 本「BOM表」；品項主檔 dim_sku／單位換算 dim_unitconv／產品名稱對照表＝採購系統同一份儀表板專用檔（GAS 雙寫同步）——照常維護，本頁即時跟上
  2. 價格優先序：廠價(即時)＝fact_vendor_price 最新季（靠 dim_price_map 對照到主檔品名，同品多供應商取最高）→ 主檔價（價格表填的）→ 憑證/換算＝估價層 → 估 → 缺
  3. 要把「估」換成真價：用「價格表 · 可改價」填單價按「存」寫回 dim_sku（會跳確認，採購系統同步生效）；配方類例外，由 Chat 更新估價層
  4. 若標「⚠ 主檔價與參考差 N 倍，暫不採用」＝主檔口徑可能錯，到價格表改對即自動接手
  5. 器具/模具為資產不計入單次成本；損耗率：食材 ×1.05、耗材 ×1.03；全部含稅。售價可按「抓 POS 售價」查近 90 天實收均價
新食譜申請表（人工送件）
  1. 填表頭與用料明細（可直接匯入主廚的食譜 .doc 檔），右側成本卡即時算成本率
  2. 主檔沒有的品項可「🆕 暫列」並手填估價；停售／過季品項會提醒但不擋
  3. 按「產出申請單」→ 複製摘要貼 LINE 給主廚／總部；核准後再複製「BOM 表貼上列」貼 BOM 本、「dim_sku 新品項列」貼主檔
  4. 草稿自動存在本機瀏覽器，重整不會消失；「⬇ 下載申請單 .json」可保存或供日後匯入
