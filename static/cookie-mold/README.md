# AI 專屬餅乾模・試玩頁用的檔案

- `mold-config.json`：模具規格（外徑、牆厚、壓紋深度…），改這個檔就改尺寸。
- `u2netp.onnx`：去背模型 U²-Net（小型版），Apache-2.0 授權，來源 https://github.com/xuebinqin/U-2-Net （ONNX 檔取自 rembg 專案發佈頁）。
- `yolox_nano.onnx`：人／動物辨識模型 YOLOX-Nano，Apache-2.0 授權，來源 https://github.com/Megvii-BaseDetection/YOLOX 。

兩個模型都在客人的瀏覽器裡執行，照片不會上傳。
