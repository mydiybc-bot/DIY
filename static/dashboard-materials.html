查價比價（季更新）
  1. 季初收集上一季各廠商送貨單／對帳單 PDF
  2. 丟給 Claude（vendor-price-tracker）產「可直接貼 Sheet 的 19 欄長表列」（含標準品名／大類／價格性質）
  3. 貼到 fact_vendor_price 分頁最底（只新增、不覆蓋，季別格式 YYYYQn）→ 重新整理本頁
  4. 器具／模具／耗材：從 Shopline 後台匯出商品明細（BulkUpdateForm），交 Claude 轉成同格式長表
食譜成本卡（資料來源與維護）
  1. 配方＝BOM 本「BOM表」；品項＝dim_sku；單位換算＝dim_unitconv——照常維護，本頁即時跟上
  2. 價格優先序：廠價(即時)＝fact_vendor_price 最新季（靠 dim_price_map 對照到主檔品名，同品多供應商取最高）→ 主檔價（價格表填的）→ 憑證/換算＝估價層 → 估 → 缺
  3. 要把「估」換成真價：用「價格表 · 可改價」填單價按「存」寫回 dim_sku（會跳確認，採購系統同步生效）；配方類例外，由 Chat 更新估價層
  4. 若標「⚠ 主檔價與參考差 N 倍，暫不採用」＝主檔口徑可能錯，到價格表改對即自動接手
  5. 器具/模具為資產不計入單次成本；損耗率：食材 ×1.05、耗材 ×1.03；全部含稅。售價可按「抓 POS 售價」查近 90 天實收均價

🚨 漲價警示（vs 前季）
本季比上一季漲超過門檻的品項，自動列出（只看外購食材，出貨中心目錄價不列入）。跌價的品項也順便告訴你。

💰 省錢機會排行（換供應商可省多少）
同一種原料有兩家以上供應商報價時，算出「最貴 vs 最便宜」每kg／L 差多少。排越前面＝議價或改單的效益越大。
📈 品類漲跌總覽（本季 vs 前季平均）
每個品類內有跨季資料的品項，取漲跌%平均。紅=平均在漲、綠=平均在跌。開會報告本季原物料行情直接看這張。
⚠️ 供應商依賴風險（單一來源品項）
整個資料裡只有一家供應商報價的原料。這些品項若被漲價或斷貨沒有備援，建議優先找第二家詢價。
📊 進階分析：議價訊號與品類價格帶展開 ▾
季內價差排行 — 值得回頭議價的品項
同一品項本季內跨店／跨日的單價落差%（＝最高÷最低−1）。落差大＝同季不同批／不同店報價不一，可回頭跟廠商確認。
品類價格帶（每kg／L）
選一個品類，每個品項畫「本季最低～最高」的價格帶（已換算、跨公司合併）。紅=落差≥30%、橘=10~30%、綠=穩定。計數類不換算、不顯示。
資料來源：食材＝廠商送貨單／對帳單／發票明細表抽取（vendor-price-tracker）；器具／模具／耗材＝出貨中心 Shopline 商品目錄（內部目錄價，非外購成交價，不做議價分析）。德麥、皓廷為單據原含稅；其餘原未稅已×1.05換算為含稅。 生鮮蔬果、整顆蛋、麵粉、鮮乳等法定免稅取原值不加稅。「每kg／L」為跨規格、跨供應商比價的基準。
