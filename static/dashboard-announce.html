📦 資料狀態讀取中…
  1. 資料放哪裡：雲端硬碟資料夾「自己做 公告及工作清單」裡的試算表「公告及工作清單_資料庫」；附檔在同資料夾的「附檔／公告編號」子資料夾。
  2. 怎麼改：一律在本頁按「✏️ 管理者模式」輸入管理者密碼後新增、修改、刪除。請不要直接改試算表（本頁會檢查格式、記錄是誰改的）。
  3. 刪除：只是標記刪除，資料列還在、附檔搬到「_已刪除」資料夾，可以找回。
  4. 公告狀態：用公告的開始日／結束日跟今天比：今天在期間內＝進行中；結束日已過＝已過期；開始日還沒到＝尚未開始；沒填結束日＝長期有效。
  5. 密碼（2026-10-06 起）：看公告不用密碼；看工作清單要「看公告」密碼；新增、修改、刪除要「管理者」密碼。兩組都在「儀表板權限中心」管理，關掉分頁就要重新輸入。
  6. 從 NUEIP 搬過來的公告標「NUEIP」字樣，保留原建立者與建立時間。
