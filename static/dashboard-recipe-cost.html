資料來源與維護 SOP
① 配方＝BOM 本「BOM表」；品項＝dim_sku；單位換算＝dim_unitconv——照常維護，本頁即時跟上。
② 價格優先序：廠價(即時)＝廠商單價追蹤表最新一季（每季貼新資料自動生效，同品多供應商取最高） → 憑證/換算＝2026-07 建置的估價層 → 估＝市價/配方推估 → 缺。
③ 要把「估」換成真價（最簡單路徑）：在採購系統 → 主檔頁（總部）把該品項的「單價」（每採購單位含稅）填上、內容量確認正確 → 本頁下次開啟自動改用真價、標「實」。不用動廠商單價表、不用改檔。配方類（克林姆/吉利丁凍）例外：請主廚給配方後由 Chat 更新估價層。
④ 器具/模具為資產不計入單次成本（2026-07-29 裁定）；損耗率沿用採購系統：食材 ×1.05、耗材 ×1.03；全部含稅。
⑤ 售價（毛利）：按「抓 POS 售價」查近 90 天全店實收均價；或手動輸入售價。
